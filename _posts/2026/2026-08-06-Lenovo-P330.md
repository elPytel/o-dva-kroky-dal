## Jak jsem nakonfiguroval P330 po nákupu?

| Parametr | Hodnota |
| --- | --- |
| Procesor | Intel Core i5-8500T 6c/6t 2.1GHz (4.1GHz Turbo) |
| RAM | 24 GB DDR4 2666MHz (8+16GB) |
| 1. M.2 NVMe | 1 TB Intel 660P |
| 2. M.2 NVMe | Optane 16 GB |

Jako operační systém jsem zvolil Ubuntu 26.04 LTS. Na Optane bude klasicky SWAP. 


## Povolení Wifi a Bluetooth
Na základní desce je přítomen M.2 slot pro Wifi/BT kartu. Součástí balení byla i anténa, která se připojuje na zadní stranu počítače. Když jsem nainstaloval Ubuntu 26.04, tak jsem zjistil, že Wifi a Bluetooth se nehlásí. Po krátkém pátrání jsem zjistil, že je potřeba v BIOSu povolit Wifi a Bluetooth. Po povolení a restartu počítače se Wifi a Bluetooth objevily v systému.

## Připojení 4K monitoru

P330 má na zadní straně:
- 2x DP (jeden jakododatečný výstup)
- 1x HDMI

iGPU v procesoru:
`Intel Corporation CoffeeLake-S GT2 [UHD Graphics 630]`

```bash
ls -1 /sys/class/drm | sed -n '/^card1/p'
card1
card1-DP-1
card1-DP-2
card1-HDMI-A-1
card1-HDMI-A-2
card1-HDMI-A-3
```

DP na HDMI redukci jeden jen na FHD. 
HDMI na HDMI kabel funguje jen na 4K@30Hz (stejný kabel v Zalmanovi funguje bez problémů na 4K@60Hz).

```bash
== card1-DP-1 ==
disconnected

== card1-DP-2 ==
disconnected

== card1-HDMI-A-1 ==
disconnected

== card1-HDMI-A-2 ==
connected
3840x2160
3840x2160
3840x2160
3840x2160
3840x2160
2560x1440
1920x1080
1920x1080

== card1-HDMI-A-3 ==
disconnected
```

### Kde je problém?
DP se umí přenout na HDMI, proto se HDMI větví zobrazolo tolik.

Ukázalo se že mám 2x HDMI kabel který podporuje 4K@60Hz. Ale HDMI sdířka na P330 je jen HDMI 1.4, takže i když kabel podporuje 4K@60Hz, tak se monitor ve výsledku připojí jen na 4K@30Hz. 

Takže pro 4K@60Hz je potřeba použít DP kabel.

Samsung monitor nemá žádní DP vstup. Všechny redukce které mám z DP na HDMI končí na FHD.

Takže budu muset koupit redukci z DP na HDMI 2.0...

Snad to: 
*AXAGON RVD-HI20N, DisplayPort -> HDMI 2.0b adapter, 4K/60Hz, HDR10*
za 300 Kč vyřeší.

Funguje!

Ale potřebujete k němu dobrý HDMI kabel, který podporuje 4K@60Hz. Ten co byl v balení s monitorem funguje dobře.

## SWAP -> optane 16GB

Optane 16GB jsem naformátoval pomocí GParted a vytvořil jsem na něm `linux-swap`. 

Vypnul jsem starý swap:
```bash
sudo swapoff /swap.img
```

Ověření:
```bash
swapon --show
```

Odstranění starého swapu z fstab:
```bash
sudo cp /etc/fstab /etc/fstab.bak
sudo sed -i '\|/swap.img|d' /etc/fstab
grep swap /etc/fstab
```

Aktivace nového swapu:
```bash
sudo swapon /dev/nvme0n1p1
```

Získání UUID nového swapu:
```bash
sudo blkid /dev/nvme0n1p1
```

Přidání nového swapu do fstab vložte:
```text
UUID=XXX none swap sw 0 0
```
Podle UUID které jste získali z příkazu `blkid`.

Ověření že swap je aktivní:
```bash
swapon --show
```

> [!tip]
Po přístím restartu ověřte že záznam v fstab je funkční a swap se automaticky aktivoval.
